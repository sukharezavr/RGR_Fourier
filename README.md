# Ряды Фурье и их численная реализация

Реализованы аналитическое разложение функций в ряд Фурье, численные методы (Симпсон, FFT), исследование сходимости и применение к реальным данным — солнечной активности.

## Файлы

- `first_functions.py` — построение графиков частичных сумм для функций `x`, `|x|`, `sgn(x)` с использованием аналитических формул.
- `coefficients.py` — сравнение методов Симпсона и FFT: время выполнения, точность коэффициентов, исследование сходимости, таблицы ошибок.
- `data_analysis.py` — анализ реальных данных (солнечные пятна): загрузка, спектр, восстановление сигнала, сжатие, MSE.
- `sunspot_data_processed.csv` — данные о среднемесячном количестве солнечных пятен за 1749–2024 гг.
